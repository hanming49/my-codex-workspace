# Q 版角色修订 V2

打开 `chibi_character_v2.blend`，场景为 `Chibi_Reference_Character`。旧版不覆盖。

本次重点修改：
- 将球形脸改为较宽、较平的脸面，调整眼距和五官贴合位置。
- 重建发帽与五束薄刘海，沿头顶垂下，去掉旧版块状刘海。
- 后发改为连续弧面，只在末端形成分组；调整发帽和后发的衔接。
- 两侧发束改薄并贴近脸颊；重建向肩部展开的白色宽领。
- 略加宽裙摆，调细格纹，减轻肤色和发色阴影。
- 默认视口将角色居中，隐藏辅助对象。

文件包含正面、侧面、背面、三分之四预览。材质均为内部程序材质，没有外部贴图依赖。部件保持独立，可调整网格和厚度修改器。未制作骨骼或表情绑定。

仍属照片/插画引导的近似三维重建，不能把自动网格检查通过等同于视觉还原完成。背面发尾分组、背部服装、隐藏连接结构为推定设计，手指、袜口及鞋子为简化结构。

## 重现
压缩包包含旧版输入 `source_v1.blend` 和改造脚本：

```bash
blender -b source_v1.blend --python rebuild.py
```

请从旧版输入执行，不要在 V2 文件上重复执行。`qa.json` 为网格检查结果，隐藏发片内侧的背向接触面为保持独立编辑而保留。
