# 角色修订 V3：头形与自然分束

打开 `chibi_character_v3.blend`，选择场景 `Chibi_Reference_Character`。V1 和 V2 均保留，不覆盖。

## 本次修改
- 将脸部最大宽度从约 1.029 缩至 0.900（约缩窄 12.5%），高度从约 0.800 缩至 0.740（约缩短 7.5%）；压平脸侧和下颌的曲率，保留圆润转角。
- 同步移动五官和耳朵，保持半睁眼与短线嘴的表情。
- 删除 V2 的整片帘状后发，重建 9 个有厚度、弯曲和独立发尖的后发对象。根部与发帽交叠，靠近下段逐渐分开；发尾长度、偏转方向不同。
- 重建 4 束不等宽的偏斜刘海和 2 束贴脸长发；厚度与细分修改器保留。
- 服装、身体、格纹、灯光与四个相机沿用 V2，便于比较本轮头形和头发的改动。

## 文件
- `chibi_character_v3.blend`：可编辑成品，材质均在文件内部，无外部贴图依赖。
- `front.png`、`side.png`、`back.png`、`three_quarter.png`：四视图。
- `rebuild_v3.py` 与 `source_v2.blend`：生成脚本及输入。运行 `blender -b source_v2.blend --python rebuild_v3.py` 可重建；不要从 V3 文件重复运行。
- `qa.json`、`model_stats.json`、`review_random.png`、`review_wire.png`：结构检查、模型统计、分件与拓扑检查图。

## 边界
这仍是依据插画进行的近似三维重建。原图未画出的背面发束排列、隐藏连接和背部服装为推定设计；没有制作毛发模拟、骨骼或表情绑定。头发使用可编辑的卡通体块，不是写实单根发丝。
自动检查仅用于检测网格问题，不代表已达到原图的视觉还原程度。为保留独立发束编辑能力，隐藏发根处少量相向接触面可保留，具体见 qa.json。

## 模型统计

本版共 57 个网格对象，评估后三角面合计 122504；整体包围盒约 1.011 × 0.819 × 1.871 Blender 单位。每个对象的三角面数量在 `model_stats.json` 中列出。

结构检查通过。保留 3 组隐藏内侧相向接触面的警告（发帽与第一束刘海、发帽与右侧贴脸发、相邻后发根部），用于独立部件接合；已检查可见表面，没有把这类警告解释为视觉还原度合格。
